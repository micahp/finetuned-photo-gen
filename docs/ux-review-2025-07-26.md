# UX Review – 2025-07-26

This document summarizes the key user-experience gaps discovered during a full walkthrough of the application on **2025-07-26**. Addressing these items will improve usability, conversion, and overall user satisfaction.

---

## 1. Onboarding & Initial Experience

- **Missing "Forgot Password" flow** – users have no self-service password reset option.
- **Inconsistent empty states**
  - Good: "My Models" page prompts free users to upgrade.
  - Bad: "Training" page shows a blank screen for free users; should mirror other premium CTAs.
- **Onboarding guidance** – first-time users are not guided through core actions (generate an image, upload selfies, etc.). Consider a lightweight tour or checklist.

## 2. Clarity & User Guidance

- **Credit visibility** – balance is hidden except on certain pages. Show remaining credits persistently in the nav (e.g. next to the avatar).
- **Model descriptions** – model dropdowns lack context. Add tooltips or one-line summaries so users know when to pick each model.
- **Incomplete stats** – "Images Generated" and "Models Trained" fields display `--`; show `0` or hide until implemented to avoid confusion.

## 3. Premium Gating Experience

- **No trial for editing** – image editing is entirely locked. Offer 1-2 free edits to showcase value and encourage upgrades.
- **Fragmented model creation** – users must switch from "Models" to "Training". Provide a direct “Create Model” button inside "My Models" or a modal to streamline the flow.

## 4. Error Handling & Feedback

- **Generic failure messages** – server errors appear as simple "Invalid email or password" or silent failures. Surface user-friendly toasts and log IDs when unexpected errors occur.
- **Job failure transparency** – unclear what happens (and whether credits are refunded) if image/video generation fails. UI should explicitly state failure reason and credit outcome.

## 5. Performance & Network

- **Gallery pagination** – repeated `/api/video/gallery` calls every few seconds even when idle (see dev console). Add debounce or polling stop once all results loaded.
- **Large bundle warnings** – critical dependency warnings from `replicate/lib/util.js`; review for tree-shaking opportunities.

---

### Recommended Next Steps

1. Add password-reset route and link on login page.
2. Audit all pages for empty state handling; ensure every blank page educates and guides.
3. Introduce persistent credit badge in navbar.
4. Implement model/tooltips and basic analytics on model selection frequency.
5. Create a fail-safe for generation jobs: refund logic + user notifications.
6. Reduce unnecessary polling on gallery endpoints.

> Tackling these items should measurably improve first-time user activation, reduce support tickets, and increase premium conversions.
